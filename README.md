## 📖 Deskripsi Project

Personal Biodata Website merupakan website statis
yang dibuat untuk memperkenalkan diri serta
menampilkan informasi pribadi secara terstruktur.

Website ini dikembangkan menggunakan HTML5 sebagai
struktur halaman dan CSS3 untuk mengatur tampilan
agar lebih menarik dan mudah digunakan.

## ✨ Fitur Website

- **Tentang Saya** — Perkenalan singkat pemilik website.
- **Biodata Diri** — Informasi pribadi dan foto profil.
- **Pengalaman** — Pengalaman organisasi dan kepanitiaan.
- **Pendidikan** — Riwayat pendidikan dalam bentuk tabel.
- **Sosial Media** — Tautan Instagram dan WhatsApp.
- **Navigasi** — Menu untuk berpindah antarbagian halaman.
- **Hover Effect** — Efek interaktif pada kartu biodata.
- **Responsive Layout** — Penyesuaian tata letak biodata pada layar kecil.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|-----------|----------|
| HTML5 | Membuat struktur dan konten website |
| CSS3 | Mengatur desain, warna, dan layout |
| Flexbox | Mengatur posisi elemen |
| Media Query | Menyesuaikan tampilan pada perangkat berbeda |

## 🚀 Cara Menjalankan

1. Clone repository ini atau download sebagai ZIP.
2. Buka folder project.
3. Pastikan file HTML, CSS, dan gambar tersedia.
4. Buka file `index.html` menggunakan browser.
5. Website siap digunakan.
